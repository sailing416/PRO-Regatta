Running Regattas Under the Racing Rules is an AI-powered web assistant that guides you through the process of preparing, reviewing, and improving official regatta documents. The app focuses on improving accuracy, completeness, and compliance—the areas where organizers benefit most from structured support.

This resource supports two main documents used in organizing sailing races:

Notice of Race (NOR)

Sailing Instructions (SIs)

The assistant does not alter or reinterpret the Racing Rules—it simply helps you apply them correctly and consistently.

What the Assistant Does
1. Notice of Race (NOR)

Learn what elements must be included according to the Racing Rules.

See what additional information is useful to include for clarity and fairness.

Upload your own NOR for automated review, rating, and feedback.

The assistant identifies missing elements, compliance issues, and omissions.

You can also request the AI to rewrite your NOR for improved structure and readability.

2. Sailing Instructions (SIs)

Learn what elements must be included according to the Racing Rules.

See what additional information is recommended for effective race management.

Upload your SIs for review and automated rating.

The assistant checks completeness and compliance with relevant rules.

Optionally, it can rewrite your SIs to make them consistent and clearly formatted.

Getting Started
Step 1 – Access the App
This AI assistant is hosted as a web resource on GitHub. Simply follow the project link to access the interface.

Step 2 – Obtain an API Key
You’ll need an API key to use the AI functions (review, rewrite, and rating features).

Sign up with the AI platform provider following their instructions on how to generate an API key.

Enter this key into the input field in the web interface.

Step 3 – API Usage and Costs
Each question, upload, or document review uses a small amount of API credit.

Costs per question are based on the provider’s published API pricing (refer to their documentation).

Fees are paid directly to the provider through your API account — none of these costs go to the author or this project.
